# 빵트리스 · Dessert Drop

모바일 웹에서 플레이하는 베이커리 테마 블록 퍼즐입니다. 가로 한 줄을 채워 디저트를 모으고 주문을 완성합니다.

## 실행

`Dessert-Drop.html`을 브라우저로 열면 실행됩니다. 별도 빌드 과정은 없습니다. 웹 서버에는 `dist/` 안의 파일을 함께 업로드합니다.

## 주요 기능

- 디저트별 점수 및 주문 완성 보너스
- 연속 줄 제거 배수
- 다음 블록과 착지 위치 표시
- 터치 버튼, 길게 누르기, 스와이프 조작
- 일시정지와 브라우저 최고 기록 저장

## 조작

모바일에서는 게임판을 탭해 회전하고 좌우로 밀어 이동합니다. 아래로 짧게 밀면 한 칸 내리고, 길게 밀면 즉시 낙하합니다. 화면 아래 버튼으로도 조작할 수 있습니다.

PC에서는 방향키로 이동 및 회전, Space로 즉시 낙하, P로 일시정지합니다.

## 파일

- `dist/`: 웹 배포용 HTML, CSS, JavaScript 및 이미지
- `Dessert-Drop.html`: 이미지와 코드를 포함한 단일 실행 파일
- `게임기획안.md`: 규칙과 점수 체계
- `빵트리스-프로토타입.png`: 화면 디자인 참고 이미지

최고 기록은 기기와 브라우저별로 저장됩니다. 실제 휴대폰에서의 화면 및 조작 검증은 추가로 필요합니다.
